🤝 Doou — Plataforma de Doações e Solidariedade

O **Doou** é uma plataforma em desenvolvimento que conecta pessoas que desejam **doar** com aquilo que já não tem valor para elas. Facilitando, através da localização, o processo de doação de itens  de forma **segura, moderna e transparente**.

O sistema está sendo construído com **backend em .NET 6** e **frontend em Next.js**, utilizando **autenticação JWT** e **integração via API REST**.

---

## 🧩 Tecnologias Utilizadas

### 🖥️ Backend (.NET 6)
- ASP.NET Core Web API  
- C#  
- Entity Framework Core  
- JWT (JSON Web Token)  
- Swagger (Swashbuckle)  
- SQL Server  
- Variáveis de ambiente (.env)  
- Injeção de dependência e arquitetura modular  

### 💻 Frontend (Next.js)
- React + TypeScript  
- Next.js 14 (App Router)  
- Axios para comunicação com a API  

### 💻 Infra
- Docker
